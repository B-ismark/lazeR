## What's new

**Laptop: updates install from inside the app**
- LazeR now checks for a new version when it opens and every few hours while it runs. Before, it only checked at launch, so a LazeR left in the tray never noticed a release.
- When one is out, a banner offers **Update now**: LazeR downloads the new version from this project's GitHub releases, checks it against the published fingerprint, swaps it in and restarts. Your phone reconnects by itself. If anything goes wrong, your current version stays as it was.
- This release still needs one manual download of `LazeR.exe` (2.6.0 doesn't have the updater). Every update after this one is a click.

**Phone: phone-as-microphone is now opt-in**
- New **Settings → Microphone → Use phone as microphone**, off by default. Off hides the Laptop / Phone switch; the laptop mic mute button works either way.

Update both apps. On the phone, **Download & install** from the update card; on the laptop, download `LazeR.exe` from this page one last time.
