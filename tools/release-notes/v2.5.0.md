## What's new

**Laptop**
- **A fresh, modern look.** The window follows your Windows light or dark mode, with rounded cards, proper switches for settings, clear status chips and a title bar that matches the window.
- **Lighter on your PC.** LazeR no longer starts PowerShell or netsh in the background while it runs, so those (and their console windows) are gone from Task Manager, and the brightness and firewall checks take milliseconds instead of a second of CPU. Your own mouse is no longer slowed by LazeR while no phone is connected.
- **"Port 50505 is already in use", explained.** LazeR now says what is really holding the port: a stuck copy of LazeR (offers to end it), another program (names it), or Windows itself reserving the port for Hyper-V, WSL or Docker (offers a one-click fix that keeps the port free from then on).
- On work laptops where IT manages the firewall, LazeR spots blocking rules that IT pushed.

**Phone**
- No changes in this release; the phone app is rebuilt with the new version number only.

Update `LazeR.exe` on the laptop. Updating the phone is optional: either side still works with the other side's older version.
