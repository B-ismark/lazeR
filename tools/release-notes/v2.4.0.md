## What's new

**Laptop**
- **Starts with Windows by itself.** The first time you open LazeR.exe it sets itself to start in the tray when you sign in, so it's there after a restart without you doing anything. It does this once: switch it off under **Show details → Start with Windows** (or in Task Manager → Startup apps) and it stays off. If you move or re-download the exe, LazeR updates the startup entry to the new place.
- **Pairing is kept in one place.** The pairing code and key now live in `%LOCALAPPDATA%\LazeR` instead of beside the exe, so your Downloads folder stays clean and replacing the exe keeps every phone paired. The first launch of 2.4.0 moves an existing pairing over by itself.
- **Clean removal.** `LazeR.exe --uninstall` removes the startup entry, LazeR's firewall rule (one admin prompt) and the saved pairing. Then delete the exe.
- **Sharp on high-resolution screens.** The window, text and QR code are no longer blurry at 125–200 % display scaling, and the cursor moves at the same speed as before.
- **The window stays where you put it**, including on a second monitor, instead of jumping back to the middle of the screen.
- **Fixes "Cancel" on the firewall prompt.** Clicking Cancel when Windows asks about LazeR adds a hidden rule that blocks phones. LazeR now spots it, and **Allow through firewall** removes it.
- **Plain-language messages.** Warnings say what happened and what to do; technical detail goes to the activity log.
- LazeR.exe now shows its version under Properties → Details.

**Phone**
- **New icon** that follows your home screen's theme on Android 13+, and a launch screen.
- **Full light and dark themes** on phones without Material You colours.
- **Shorter error messages.** "Couldn't reach the laptop" and similar messages fit on one line, with a **Why?** button for the possible causes. Scanner and update errors are in plain language.
- **Landscape and gesture navigation:** nothing sits under the system bars or the camera cutout any more.
- TalkBack reads the sliders' values.

Update both halves: `LazeR.exe` on the laptop, `LazeR.apk` on the phone. Either side still works with the other side's older version.
