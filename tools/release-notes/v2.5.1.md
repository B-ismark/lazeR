## What's fixed

**Laptop**
- **Really no more PowerShell or netsh in the background.** 2.5.0 meant to stop LazeR starting them, but two firewall checks still fell back to them on many PCs: one whenever LazeR's firewall rule wasn't there yet, and one on work laptops whose firewall IT manages. Both checks now run inside LazeR in a few milliseconds, so Task Manager shows LazeR alone.

**Phone**
- No changes; the phone app is rebuilt with the new version number only.

Update `LazeR.exe` on the laptop. Updating the phone is optional.
